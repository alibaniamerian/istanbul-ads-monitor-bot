# ربات مشاهده‌گر آگهی‌ها

این نسخه فقط پیام‌های جدید گروه را بررسی می‌کند و گزارش خصوصی می‌فرستد. هیچ پیام، کاربر یا تنظیمی را در گروه حذف یا تغییر نمی‌دهد.

## راه‌اندازی

1. در BotFather یک ربات بسازید و Privacy Mode را خاموش کنید، یا ربات را به‌عنوان ادمین گروه اضافه کنید. ربات برای نسخه مشاهده‌گر به دسترسی حذف پیام نیاز ندارد.
2. در گفت‌وگوی خصوصی با ربات `/start` بفرستید و شناسه عددی گفت‌وگوی خودتان را در `ADMIN_CHAT_ID` قرار دهید.
3. فایل `.env.example` را به `.env` تبدیل کنید و توکن و شناسه مدیر را وارد کنید.
4. وابستگی‌ها را نصب و ربات را اجرا کنید:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bot.py
```

برای اجرای تست‌های منطق تشخیص:

```powershell
python -m pytest -q
```

## فعال‌کردن تحلیل Gemini

برای تحلیل بهتر آگهی‌های فارسی، ترکی، عکس‌دار و چندبخشی، یک کلید Gemini API از Google AI Studio بگیرید و فقط در فایل `.env` قرار دهید:

```env
GEMINI_API_KEY=کلید_واقعی_شما
GEMINI_MODEL=gemini-3.6-flash
```

کلید را در گروه یا مخزن کد ارسال نکنید. اگر `GEMINI_API_KEY` خالی باشد، ربات بدون AI و با تشخیص محلی کار می‌کند. اگر درخواست Gemini به‌دلیل سهمیه یا خطای شبکه موفق نشود، گزارش محلی همچنان ارسال می‌شود.

## رفتار فعلی

- فقط پیام‌هایی که شبیه آگهی باشند بررسی می‌شوند.
- وجود قیمت و یکی از مناطق شناخته‌شده استانبول گزارش می‌شود.
- شباهت فقط با آگهی‌های همان فرستنده در ۴۸ ساعت گذشته محاسبه می‌شود.
- در صورت فعال‌بودن Gemini، همه آگهی‌های ثبت‌شده همان فرستنده در ۴۸ ساعت گذشته برای مقایسه به آن داده می‌شوند.
- آگهی مشابه فقط به‌عنوان «احتمال تکراری» گزارش می‌شود و هیچ اقدامی در گروه انجام نمی‌شود.
- داده‌ها در SQLite محلی ذخیره می‌شوند.
- وقتی کلید Gemini فعال باشد، متن و تصاویر آگهی برای تحلیل به سرویس Gemini ارسال می‌شوند.
- هر روز بعد از ساعت ۷ صبح به وقت استانبول، تقویم همان روز در گروه‌های ثبت‌شده منتشر می‌شود؛ این پیام شامل تاریخ شمسی، میلادی و ترکی است و برای هر گروه فقط یک‌بار در روز ارسال می‌شود.
- وقتی Gemini فعال باشد، بین آگهی واقعی و گفت‌وگوی معمولی یا مذاکره تفکیک می‌کند و برای گفت‌وگوهای عادی تذکر اصلاحی نمی‌فرستد.
- با Gemini فعال، همه پیام‌های متنی و عکس‌دار اعضای عادی ابتدا برای تشخیص «آگهی یا گفت‌وگو» تحلیل می‌شوند؛ پیام‌های گفت‌وگویی ذخیره یا گزارش نمی‌شوند.

تشخیص منطقه و آگهی عمداً ساده و قابل بازبینی است؛ بعد از چند روز گزارش واقعی می‌توان فهرست مناطق، آستانه شباهت و فرمت گزارش را دقیق‌تر کرد.
